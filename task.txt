--------------------------------------------------------------------------------
  HOW THE WORKFLOW WORKS (end-to-end)
--------------------------------------------------------------------------------

1. UPLOAD
   User clicks "New Upload" in the UI.
   Frontend calls GET /ik-auth to get token, expire, signature.
   Frontend SDK (ImageKit JS) uploads the file directly to ImageKit.
   During upload, the extensions parameter carries an AI Task config
   that auto-tags the image and sets initial metadata (Status = "Pending").

2. QUEUE POPULATION
   After upload, the frontend calls GET /api/search?folder=<folder>
   The backend calls imagekit.listFiles() with a searchQuery.
   Response is mapped via mapItem() and returned as JSON.
   The frontend renders each file as a row in the review queue.

3. REVIEW ACTIONS
   Reviewer clicks Approve → frontend calls POST /api/approve with fileId + note
   Backend calls imagekit.updateFileDetails(fileId, { customMetadata: { Status: "Approved", Reviewer: ..., ReviewedAt: ... } })

   Reviewer clicks Reject → frontend calls POST /api/reject with fileId + reason
   Backend calls imagekit.updateFileDetails(fileId, { customMetadata: { Status: "Rejected", Reason: ..., Reviewer: ... } })

   Reviewer clicks Revert → frontend calls POST /api/revert with fileId
   Backend calls imagekit.updateFileDetails(fileId, { customMetadata: { Status: "Pending" } })

4. AI TASKS (automatic on upload)
   When a file is uploaded with an extensions config, ImageKit's AI:
   - Reads the image using an LLM
   - Runs your configured sub-tasks (select_tags, select_metadata, yes_no)
   - Applies tags or metadata automatically
   This means every uploaded asset arrives with AI-generated tags and
   a pre-suggested content category — reviewers only confirm or override.

--------------------------------------------------------------------------------
  PHASE 3 — AI Tasks Integration (the new feature)
--------------------------------------------------------------------------------

Overview:
  AI Tasks run at upload time (or via update) using the "extensions" parameter.
  You define tasks in JSON — each task has a type, instruction, and actions.

Three task types:
  1. select_tags     — picks tags from your vocabulary list
  2. select_metadata — sets a custom metadata field from allowed values
  3. yes_no          — asks a true/false question, triggers different actions

How to use in this project:

  A. Auto-tag content type on upload
     Extension config passed to imagekit.upload():

     extensions: [{
       name: "google-auto-tagging",    // or use AI task name
       // For AI Tasks use the "ai-task" extension:
     }]

     More specifically, for AI Tasks:
     extensions: [{
       name: "saved-extension-id",     // reference a Saved Extension from dashboard
     }]

     OR inline config:
     extensions: [{
       name: "ai-task",
       options: {
         tasks: [
           {
             type: "select_tags",
             instruction: "What is the primary subject of this image? Choose all that apply.",
             vocabulary: ["product", "lifestyle", "banner", "portrait", "landscape", "infographic"],
             actions: {
               addTags: { minCount: 1, maxCount: 3 }
             }
           },
           {
             type: "yes_no",
             instruction: "Does this image contain visible faces or identifiable people?",
             actions: {
               yes: { addTags: ["contains-people"] },
               no:  { addTags: ["no-people"] }
             }
           },
           {
             type: "select_metadata",
             instruction: "What is the primary color palette of this image?",
             field: "ColorPalette",           // your custom metadata field name
             vocabulary: ["warm", "cool", "neutral", "vibrant", "monochrome"]
           }
         ]
       }
     }]

  B. Run AI Tasks on existing files via update
     imagekit.updateFileDetails(fileId, {
       extensions: [{ name: "ai-task", options: { tasks: [...] } }]
     })
     Use this for bulk re-tagging of old assets.

  C. Bulk AI enrichment script
     Write a Node script that:
     1. Calls imagekit.listFiles({ searchQuery: 'customMetadata.Status = "Pending"' })
     2. Loops each file, calls updateFileDetails with AI Task extensions
     3. Logs result — assets get tags + metadata automatically
